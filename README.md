# Product Inventory Management Application

A full-stack web application designed for efficient inventory tracking. Built with a robust **FastAPI** backend and a dynamic **React.js** frontend, this system streamlines warehouse and stock workflows.

## 🚀 Key Features

* **Complete CRUD Operations:** Seamlessly add, view, update, and delete product profiles.
* **Efficient Inventory Tracking:** Real-time logging of stock counts, pricing, and product details.
* **Relational Database Storage:** Safe, transactional storage utilizing a relational database model.
* **Modern API Architecture:** Fast, automatically documented RESTful endpoints.

## 🛠️ Tech Stack

### Backend
* **Framework:** FastAPI (Python)
* **Database:** PostgreSQL
* **ORM:** SQLAlchemy
* **Database Migrations:** Alembic

### Frontend
* **Library:** React.js (Node.js runtime)
* **Markups & Styling:** HTML5, CSS3
